claude-mirror – privacy policy

claude-mirror is used only by its owner, with the owner's own Google account.

  • Access: the app requests only the drive.file scope. It can see and change only the files that it created itself in the owner's Google Drive. It cannot see any other files.
  • Use: it creates and updates text documents with content from the owner's own git repository.
  • Storage: the OAuth token is stored only on the owner's computer, in a file readable only by the owner. No data is stored on any server operated by the app.
  • Sharing: no Google user data is sold, shared or transferred to anyone.
  • Deletion: the owner can revoke access at any time at myaccount.google.com/permissions.
